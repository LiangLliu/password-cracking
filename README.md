# Password Cracking Tool

[中文文档](./README_CN.md) | [English](./README.md)

A high-performance document password cracking tool written in Rust, supporting ZIP, PDF, and Office documents with dictionary, brute-force, and hybrid (rule-based) attacks.

> **Warning**: This tool is for legitimate purposes only — recovering your own password-protected files or authorized security testing. Do not use for illegal purposes.

## Features

- **Multi-format**: ZIP (ZipCrypto + AES), PDF (RC4-40/128, AES-128/256, owner passwords), Office (Agile AES-256)
- **Four attack modes**: Dictionary, brute-force, mask (`?d?d?l?l`), hybrid (dictionary + rules)
- **High performance**: FIFO worker pool with adaptive batching; 11M+ ZIP passwords/sec
- **Auto-detection**: Identifies file format by magic bytes, not just extension
- **Two-phase verification**: Fast header check rejects ~99% of wrong passwords before full decryption
- **Resumable**: `--checkpoint`/`--resume` survives interruptions
- **Streaming wordlists**: memory-mapped, flat memory for huge lists
- **Unix friendly**: man page, shell completions, `.deb`/`.rpm`/`.apk`, install script
- **Cross-platform**: Linux, macOS

## Quick Start

### Install

```bash
# Homebrew (macOS / Linux)
brew install LiangLliu/tap/password-cracking

# Debian / Ubuntu / Raspberry Pi OS (signed APT repository)
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://lianglliu.github.io/password-cracking/key.gpg \
  | sudo tee /etc/apt/keyrings/password-cracking.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/password-cracking.gpg] https://lianglliu.github.io/password-cracking stable main" \
  | sudo tee /etc/apt/sources.list.d/password-cracking.list
sudo apt update && sudo apt install password-cracking

# Arch Linux (AUR; package generated by CI, see docs/DISTRIBUTION.md)
yay -S password-cracking-bin

# Docker
docker run --rm -v "$PWD:/data" ghcr.io/lianglliu/password-cracking --version

# Any Rust platform (crates.io publishing pending; build from git today)
cargo install --git https://github.com/LiangLliu/password-cracking

# Static binary script (Linux / macOS)
curl -fsSL https://raw.githubusercontent.com/LiangLliu/password-cracking/master/scripts/install.sh | sh
```

See [Distribution Channels](docs/DISTRIBUTION.md) for signing keys, package
versions and troubleshooting.

### Usage

```bash
# Dictionary attack
password-cracking -f document.zip dictionary -w passwords.txt

# Brute-force (4-6 digit PIN)
password-cracking -f document.pdf brute-force -c digits --min-length 4 --max-length 6

# Mask (digit digit lower lower, e.g. 92eo)
password-cracking -f document.zip mask -m "?d?d?l?l"

# Hybrid (dictionary + rules)
password-cracking -f document.docx hybrid -w dict.txt --capitalize --l33t --append-digits 99

# Resume an interrupted brute-force run
password-cracking -f document.pdf brute-force -c alnum --min-length 1 --max-length 8 \
  --checkpoint progress.ck --resume

# Quiet mode (for scripting: prints only the password)
password-cracking -q -f document.zip dictionary -w passwords.txt
```

## Performance

| Format | Encryption | Speed (passwords/sec) |
|--------|-----------|----------------------|
| ZIP | ZipCrypto | 11,000,000+ |
| PDF | RC4-128 | 530,000+ |
| Office | Agile AES-256 | 500+ |

Performance depends on CPU cores, encryption type, and password complexity.

## Architecture

```
src/
  main.rs              CLI entry point
  lib.rs               public exports
  cli/                 clap v4 argument parsing
  engine/              Rayon + crossbeam cracking engine
  formats/             PasswordVerifier trait + ZIP/PDF/Office implementations
  generators/          PasswordSource trait + dictionary/brute-force/mask/rules
  utils/               character sets, formatting, validation
```

## Limitations

- **Office**: only Agile Encryption (v4, Office 2010+). Legacy
  CryptoAPI/ECMA-376 standard encryption (old `.doc`/`.xls`/`.ppt`) is not yet
  supported and fails with a clear error.
- **RAR5 / 7z**: not yet supported (planned; see `docs/RELEASE_LINUX.md` and
  the capability roadmap).
- **PDF**: user and owner passwords are supported for RC4/AES; empty-password
  and certificate-based encryption are out of scope.
- **ZIP**: AES and ZipCrypto; split/multi-volume archives are not supported.
- **Checkpoints** for dictionary attacks assume the wordlist is unchanged
  between runs.
